# 🐱 ねこだるまおとし

ブラウザで遊べる HTML5 の「だるまおとし」ゲームです。段はぜんぶお菓子！ 一番上に座っているねこを落とさないように、下のお菓子をハンマーでたたき出しましょう。
iPhone / Android のブラウザでは指で、PC ではマウスかキーボードで遊べます。

## 遊び方

- 画面の**左半分**をタップすると左から、**右半分**をタップすると右からハンマーで一番下のお菓子をたたきます（PC は ← / → キーか A / D キー）。
- 下の**パワーメーター**の針が真ん中（PERFECT）にあるときにたたくほど、きれいに抜けます。
  - 左端（よわい）だと、お菓子が抜けずに揺れるだけです。
  - 右端（つよすぎ）だと大きく揺れます。
- たたくと積み木が**ぐらぐら**揺れます。たたいた側と反対側に押されるので、傾いている側からたたくと揺れをおさえられます。揺れすぎるとねこが落ちてゲームオーバーです。
- 制限時間内に全部抜いて、ねこが床に座ればクリアです。
- 段数は 3 段から始まり、クリアするたびに 1 段ずつ増えます（最大 30 段）。30 段に達したあとはメーターが速くなりながら続きます。

### おかし図鑑

お菓子ごとに特徴があります。画面下の「つぎ：〇〇」で次にたたくお菓子がわかり、パワーメーターの判定の広さもそのお菓子に合わせて変わります。

| お菓子 | 登場 | 特徴 |
| --- | --- | --- |
| ドーナツ | STAGE 1〜 | 判定が広くてぬけやすい |
| マカロン | STAGE 1〜 | かるいので、たたいても揺れにくい |
| ショートケーキ | STAGE 1〜 | ふわふわで大きく揺れる。得点2倍 |
| 板チョコ | STAGE 3〜 | かたくて2回たたかないとぬけない。得点2倍 |
| プリン | STAGE 3〜 | 積んであるあいだ揺れがおさまりにくい。得点1.5倍 |
| おもち | STAGE 4〜 | ねばって判定がせまい。得点2倍 |
| 金のカステラ | ときどき | レアなお菓子。得点3倍 |

ねこが座っている一番上の段は、ホールケーキ・マシュマロ・ジャンボプリン・いちご大福に変身します。

### おじゃまイベント

- **一番上の段が変形**：ねこが座っている段は、ときどきお菓子の種類（ホールケーキ・マシュマロ・ジャンボプリン・いちご大福）と幅がランダムに変わります。せまいほど揺れやすくなります。
- **ねこの座り直し**（STAGE 2〜）：ねこがときどき座り直して、座る場所が左右にずれます。はしに寄るほど積み木がそちらに傾きやすくなります。
- **風**（STAGE 2〜）：「かぜがくるよ」の予告のあと、数秒間横から風に押されます。
- **のらねこ乱入**（STAGE 3〜）：ときどき別のねこが走ってきて、途中の段を横にずらしていきます。ずれた段は重心をかたよらせますが、たたき出せば元にもどります。

## 得点

| 内容 | 点数 |
| --- | --- |
| PERFECT / GOOD / OK / つよすぎ | 100 / 50 / 20 / 10 |
| お菓子の得点倍率 | 1〜3 倍（おかし図鑑を参照） |
| コンボ（PERFECT・GOOD の連続） | 5 コンボごとに倍率 +0.5（最大 3 倍） |
| ステージクリア | ステージ数 × 100 |
| 残り時間 | 1 秒につき 20 |
| ノーミスでクリア | 300 |

ゲームオーバー時にトップ10に入ると名前を登録でき、ランキング（端末のブラウザに保存）で得点を競えます。結果はシェアボタンで共有できます。

## 起動方法

`index.html` 1 ファイルだけで動きます。外部ライブラリやビルドは不要です。

- ローカル: `index.html` をブラウザで開く

## GitHub Pages で公開する

`.github/workflows/pages.yml` で、プッシュするたびに GitHub Pages へ自動で公開されます。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「Deploy to GitHub Pages」を実行する（以降はプッシュごとに自動で実行）

公開 URL は `https://kazeellegard-dev.github.io/daruma_game/` です。
iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」すると全画面で遊べます。
