# 🐱 ねこだるまおとし

ブラウザで遊べる HTML5 の「だるまおとし」ゲームです。段はぜんぶお菓子！ 一番上に座っているねこを落とさないように、下のお菓子をハンマーでたたき出しましょう。
iPhone / Android のブラウザでは指で、PC ではマウスかキーボードで遊べます。

## 遊び方

- 画面の**左半分**をタップすると左から、**右半分**をタップすると右からハンマーで一番下のお菓子をたたきます（PC は ← / → キーか A / D キー）。
- 下の**パワーメーター**の針が真ん中（PERFECT）にあるときにたたくほど、きれいに抜けます。
  - 左端（よわい）だと、お菓子が抜けずに揺れるだけです。
  - 右端（つよすぎ）だと大きく揺れます。
- たたくと積み木が**ぐらぐら**揺れます。たたいた側と反対側に押されるので、傾いている側からたたくと揺れをおさえられます。揺れすぎるとねこが落ちてゲームオーバーです。
- 制限時間内に全部抜いて、ねこが床に座ればクリアです。
- **PERFECT** を出すと残り時間が 0.7 秒ふえます（その段の制限時間が上限）。
- 段数は 3 段から始まり、クリアするたびに 1 段ずつ増えます（最大 30 段）。30 段に達したあとはメーターが速くなりながら続きます。

### おかし図鑑

お菓子ごとに特徴があります。画面下の「つぎ：〇〇」で次にたたくお菓子がわかり、パワーメーターの判定の広さもそのお菓子に合わせて変わります。

| お菓子 | 登場 | 特徴 |
| --- | --- | --- |
| ドーナツ | STAGE 1〜 | 判定が広くてぬけやすい |
| マカロン | STAGE 1〜 | かるいので、たたいても揺れにくい |
| ショートケーキ | STAGE 1〜 | ふわふわで大きく揺れる。得点2倍 |
| 板チョコ | STAGE 3〜 | かたくて2回たたかないとぬけない。得点2倍 |
| プリン | STAGE 3〜 | 積んであるあいだ揺れがおさまりにくい。得点1.5倍 |
| おもち | STAGE 4〜 | ねばって判定がせまい。得点2倍 |
| カステラ | STAGE 2〜 | ずっしり重くて、積んであるあいだ揺れがおさまりやすい |
| 金のカステラ | ときどき | レアなお菓子。得点3倍 |

お菓子によって**パーフェクトの位置**がちがいます。やわらかいお菓子（プリン・ショートケーキ・マシュマロなど）は「よわい」寄り、かたいお菓子（板チョコ・おもちなど）は「つよい」寄りです。

ねこが座っている一番上の段は、ホールケーキ・マシュマロ・ジャンボプリン・いちご大福に変身します。

やわらかいお菓子（プリン・おもち・マシュマロ・ケーキなど）は、着地や揺れでぷるんっとつぶれたりゆがんだりして、上の段もいっしょに弾みます。つやつやのハイライトや「ぷるんっ」「もちっ」の文字と音つき。かたいお菓子（板チョコ・カステラ）はゆがまず、シャープなふちとキラッと光る反射、「カチッ」という音になります。

### ねこ・ハンマー

5ステージクリアするごとに、まだ持っていないねこかハンマーがランダムでもらえます（プレゼント箱の演出つき）。タイトルの「ねこ・ハンマー」でえらべます。全部そろうと、代わりにボーナス +1000 点。

| 茶トラ「トラ」 | バランスのいい、ふつうのねこ（最初から） |

| 黒ねこ「クロ」 | 風に強い（風の力が半分） |
| 三毛ねこ「ミケ」 | のらねこが来にくく、押す力も弱い |
| サバトラ「サバ」 | 座り直しをしない |
| シャムねこ「シャム」 | パーフェクトの幅1.15倍 |
| ハチワレ「ハチ」 | 制限時間1.25倍 |
| ロシアンブルー「ブルー」 | 揺れがおさまりやすい |
| スコティッシュ「たれみみ」 | たたいたときの揺れ0.88倍 |
| 招きねこ「まねき」 | 金のカステラが出やすく、スコア1.05倍 |

### おじゃまイベント

- **一番上の段が変形**：ねこが座っている段は、ときどきお菓子の種類（ホールケーキ・マシュマロ・ジャンボプリン・いちご大福）と幅がランダムに変わります。せまいほど揺れやすくなります。
- **ねこの座り直し**（STAGE 2〜）：ねこがときどき座り直して、座る場所が左右にずれます。はしに寄るほど積み木がそちらに傾きやすくなります。
- **風**（STAGE 2〜）：「かぜがくるよ」の予告のあと、数秒間横から風に押されます。
- **のらねこ乱入**（STAGE 3〜）：ときどき別のねこが走ってきて、途中の段を横にずらしていきます。ずれた段は重心をかたよらせますが、たたき出せば元にもどります。

### ふってくるアイテム（STAGE 3〜）

ときどき空から物がふってきます。お菓子（いいこと）が7割、お菓子じゃないもの（わるいこと）が3割です。タップするととれます（そのタップではハンマーをふりません）。とらずに放っておけば何も起きません。

| アイテム | 種類 | 効果 |
| --- | --- | --- |
| キャンディ | お菓子（いいこと） | 6秒間パワーメーターがゆっくりに |
| クッキー | お菓子（いいこと） | 残り時間 +3秒 |
| ぺろぺろキャンディ | お菓子（いいこと） | 揺れがぴたっとおさまり、4秒間揺れにくい |
| こんぺいとう | お菓子（いいこと） | 6秒間 PERFECT の幅が広がる |
| ながぐつ | お菓子じゃない（わるいこと） | いつもより強い突風がふく |
| さかなのほね | お菓子じゃない（わるいこと） | のらねこの大群が走ってきて、3匹つづけて段をずらす |
| めざましどけい | お菓子じゃない（わるいこと） | 5秒間パワーメーターが速くなる |

お菓子はきらきら光り、お菓子じゃないものはもやもやしています。効果中は画面左上にのこり秒数が出ます。

### ミニゲームとチートアイテム（3〜5ステージごと）

ステージをクリアしたあと、3〜5ステージごとにランダムで **ミニゲームのチャンス** が来ます。「やる！」「やらない」を選べます（やらなくても損はしません）。

| ミニゲーム | ルール |
|---|---|
| 🐟 おさかなキャッチ | ふってくるおさかなを10秒で8ひきタップ（金のおさかなは2ひきぶん） |
| 🐭 ねずみたたき | あなから出てくるねずみを12秒で10ぴきタップ |
| 🐱 ねこあわせ | おなじねこのカードを20秒で3くみそろえる |
| 🐾 かつおぶしけずり | 6秒で30回れんだ |
| 🧺 ねこドロップ | 動くかごにねこを落として、5回のうち3回入れる |

クリアすると、ふつうでは手に入らない **チートねこ・チートハンマー** のどれかがもらえます。

| チートねこ | とくちょう |
|---|---|
| にじ | パーフェクトの幅が2倍 |
| ロボ | 制限時間2倍・風とのらねこがきかない |
| ふわふわ | 揺れ0.5倍・おさまり2倍 |

| チートハンマー | とくちょう |
|---|---|
| いなずまハンマー | 得点3倍 |
| ジャンボハンマー | パーフェクトの幅1.8倍・かたいチョコも1回 |
| とけいハンマー | PERFECTで時間+2秒・揺れ0.7倍 |

- もらったアイテムは **🐾 肉球バッグ** に、ねこ・ハンマーそれぞれ1つだけしまえます。同じ種類の2つめをもらうと「交換する？」と聞かれます。
- ゲーム中は画面の左上に **🐾 ボタン** が出ます。タップすると肉球バッグが開いて（ゲームは止まります）、**好きなタイミングで使えます**。
- 使ったアイテムの効果は **そのステージのあいだだけ**。ステージが終わるとなくなります。
- 肉球バッグは **そのゲームのあいだだけ** です。ゲームオーバーやタイトルにもどるとからっぽになります。
- チートアイテムを使ってあそんだ記録には、ランキングで 🐾 がつきます。

## 画面と音

- **タイトル画面**：ハンマーをかついだねこが、ケーキの上でゆれたりジャンプしたりします。ねこをタップすると大ジャンプ！
- **BGM**：タイトルはオルゴール風、ゲーム中は弾むようなおやつタイムの曲（ブラウザ内で合成、音声ファイル不要）。残り時間が少なくなると少し速くなります。
- 右上の 🎵 で BGM、🔊 で効果音をそれぞれ ON/OFF できます（設定は保存されます）。iPhone はマナーモード（消音スイッチ）だと音が出ないことがあります。
- **データリセット**：「ねこ・ハンマー」画面のいちばん下のボタンから、ハイスコア・ランキング・集めたねこ／ハンマーを消せます（確認画面つき。音の設定は残ります）。
- **背景**：パステルの空ににじ、ホイップクリームの雲、おかしの丘、ペロペロキャンディ、ギンガムチェックのテーブルクロス。

## 起動方法

ゲーム本体は `index.html` 1 ファイルだけで動きます。外部ライブラリやビルドは不要です。

- ローカル: `index.html` をブラウザで開く

## GitHub Pages で公開する

`.github/workflows/pages.yml` で、プッシュするたびに GitHub Pages へ自動で公開されます。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「Deploy to GitHub Pages」を実行する（以降はプッシュごとに自動で実行）

公開 URL は `https://kazeellegard-dev.github.io/daruma_game/` です。
iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」すると全画面で遊べます（一度開けばオフラインでも遊べます）。

## iPhone / iPad アプリ版（App Store）

[Capacitor](https://capacitorjs.com/) で `index.html` をそのままアプリに入れています。**Mac は不要**で、ビルドと TestFlight へのアップロードは GitHub Actions（`.github/workflows/ios.yml`）の Mac 環境で行います。

### ふだんの開発の流れ

1. `index.html` を直して push → GitHub Pages の Web 版で動作確認（今まで通り）
2. アプリに出したくなったら `package.json` の `version` を上げる（例 `1.0.0` → `1.1.0`）
3. **Actions → iOS アプリ → Run workflow** を実行 → 10〜30 分ほどで TestFlight に届く
4. TestFlight アプリで実機確認 → App Store Connect で審査に提出

`ios/` などを変えて push したときは、署名なしでビルドできるかだけを自動で確認します。

### 最初に 1 回だけ必要な設定

| GitHub の Secret | 中身 |
|---|---|
| `ASC_KEY_ID` | App Store Connect API キーのキー ID |
| `ASC_ISSUER_ID` | 同じ画面の Issuer ID |
| `ASC_KEY_P8` | ダウンロードした `AuthKey_XXXX.p8` の中身（テキスト全体） |
| `APPLE_TEAM_ID` | Apple Developer の Team ID |

- API キーは App Store Connect の「ユーザとアクセス → 統合 → App Store Connect API → チームキー」で、アクセス権 **Admin** で作成します（署名用の証明書をクラウドで自動作成するため）。
- App Store Connect の「アプリ」で新規アプリを作り、バンドル ID に `dev.kazeellegard.nekodaruma` を選びます（一覧に無いときは developer.apple.com の Identifiers で登録）。

### ファイル

| パス | 内容 |
|---|---|
| `capacitor.config.json` | アプリ名・バンドル ID など |
| `ios/` | Xcode プロジェクト（Capacitor が生成） |
| `scripts/build-web.mjs` | アプリに入れる Web ファイルを `www/` に集める |
| `assets-src/` | アイコン・起動画面の元画像（`renderIcon` でゲームの絵から生成） |
| `icons/`, `manifest.webmanifest`, `sw.js` | Web 版のホーム画面アイコンとオフライン対応 |
| `privacy.html` | プライバシーポリシー（App Store の申請に使う） |

アプリ版では、セーブデータを localStorage に加えて端末の設定領域（Capacitor Preferences）にも保存し、iOS に消されないようにしています。
ダイナミックアイランドやホームバーの大きさは、iOS 側（`ios/App/App/MainViewController.swift` の SafeArea）からゲームに渡しています。

### 広告（AdMob）

アプリ版だけ、画面のいちばん下に AdMob のバナー広告を常に表示します（Web 版には出ません）。いまは **Google のテスト用 ID** なので「Test Ad」と書かれた広告が出ます。本番の広告に切り替えるときは次の 2 か所を AdMob の管理画面で発行した ID に書き換えます。

| 場所 | 中身 |
|---|---|
| `index.html` の `ADMOB.bannerId`（と `testing: false`） | 広告ユニット ID（`ca-app-pub-XXXX/YYYY`） |
| `ios/App/App/Info.plist` の `GADApplicationIdentifier` | アプリ ID（`ca-app-pub-XXXX~ZZZZ`） |

広告の分だけ下のすき間（`--sab`）を広げて、ゲームの画面が広告に隠れないようにしています。
