# 🐱 ねこだるまおとし

ブラウザで遊べる HTML5 の「だるまおとし」ゲームです。一番上に座っているねこを落とさないように、下のだるまをハンマーでたたき出しましょう。
iPhone / Android のブラウザでは指で、PC ではマウスかキーボードで遊べます。

## 遊び方

- 画面の**左半分**をタップすると左から、**右半分**をタップすると右からハンマーで一番下のだるまをたたきます（PC は ← / → キーか A / D キー）。
- 下の**パワーメーター**の針が真ん中（PERFECT）にあるときにたたくほど、きれいに抜けます。
  - 左端（よわい）だと、だるまが抜けずに揺れるだけです。
  - 右端（つよすぎ）だと大きく揺れます。
- たたくと積み木が**ぐらぐら**揺れます。たたいた側と反対側に押されるので、傾いている側からたたくと揺れをおさえられます。揺れすぎるとねこが落ちてゲームオーバーです。
- 制限時間内に全部抜いて、ねこが床に座ればクリアです。
- 段数は 3 段から始まり、クリアするたびに 1 段ずつ増えます（最大 30 段）。30 段に達したあとはメーターが速くなりながら続きます。

## 得点

| 内容 | 点数 |
| --- | --- |
| PERFECT / GOOD / OK / つよすぎ | 100 / 50 / 20 / 10 |
| 金色のだるま | 3 倍 |
| コンボ（PERFECT・GOOD の連続） | 5 コンボごとに倍率 +0.5（最大 3 倍） |
| ステージクリア | ステージ数 × 100 |
| 残り時間 | 1 秒につき 20 |
| ノーミスでクリア | 300 |

ゲームオーバー時にトップ10に入ると名前を登録でき、ランキング（端末のブラウザに保存）で得点を競えます。結果はシェアボタンで共有できます。

## 起動方法

`index.html` 1 ファイルだけで動きます。外部ライブラリやビルドは不要です。

- ローカル: `index.html` をブラウザで開く
- スマホで遊ぶ: GitHub Pages などで公開して、その URL を iPhone の Safari で開く（「ホーム画面に追加」で全画面で遊べます）
